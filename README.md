One sentence, up to 200 characters, on the best advice I ever received — a
make.fun entry program. The program writes the sentence to
`/output/entry.txt` and prints it to stdout.

- Bounty: https://make.fun/bounty/u-pangg7-the-best-advice-i-ever-got-358cefb0
- Referral: https://make.fun/r/0ene8b3q

## Run

```sh
node main.ts
```

## Entry

> My father said never sign a promise on a good day, because the bad days are the ones that come to collect it.

109 characters, 23 words, one sentence.
